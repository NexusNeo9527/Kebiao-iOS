# 课表

原生 iOS 17+ SwiftUI 课表应用。它提供周课表、课程添加/编辑/删除、本机持久化、本地上课提醒、主屏幕“今日课表”小组件，以及锁屏/灵动岛实时活动；首次运行自带可删除的示例课程。

## v1.4.0 核心功能

- 在“课表”页顶部切换、管理多个课表，每张独立保存学期、周数和作息；通知、小组件及实时活动跟随当前课表。
- 一门课程可添加多个时段，各自设置星期、精确周次、教师、教室、节次、自定义时间及提醒。支持每周、单周、双周、自选分段周次，也可添加具体日期的补课。
- “课表设置”可修改第一周日期、1–30 周的学期长度和最多 12 节作息的开始/结束时间；默认课长包含首节至末节之间的课间。
- 点击具体日期的课程可“仅调整本次”，停课或改期不影响其他安排；在课程编辑中的临时调整记录恢复原安排，保存后生效。
- “备份与导出”可保存全部课表的 JSON 备份、预览并恢复备份、撤销完整恢复，以及按日期范围导出实际生效的 ICS 日历。

旧课程会迁入默认课表，保留原 UUID 和旧数据。损坏数据或未知版本不会被示例课程覆盖；编辑会暂停，可导出原始数据并从备份恢复。备份文件保留课程信息，请自行选择保存和分享的位置。

## 在 Mac 上运行

1. 推荐用 Xcode 26 或更高版本打开 `Kebiao.xcodeproj`；Xcode 15/16 仍可构建 iOS 17/18 兼容功能。
2. 在 Signing & Capabilities 选择你的 Apple 开发团队，并将 App 与 Widget 的 Bundle Identifier 改为自己的唯一标识。
3. 为两个 target 注册并启用相同的 App Group（默认 `group.com.example.kebiao`），确保它包含在两者的签名和 provisioning profile 中。
4. 选择 iPhone 模拟器或真机后运行。

课程资料只写入本机 `UserDefaults`，不会上传到网络。App 使用统一浅色外观。ICS 支持单次事件、按日/周重复、INTERVAL、COUNT、UNTIL、EXDATE、RDATE 和命名时区；无法支持的复杂重复规则会提示并跳过。没有结束日期的重复事件仅导入 30 周，其他重复事件最多展开两年。

## 上课提醒与灵动岛

1. 在课程编辑页设置真实的开始时间，并在“提醒”页设置本学期第一周日期。
2. “自动实时活动”默认开启，独立于通知开关。打开 App 后会显示当天 6 小时内的当前或下一门课；支持灵动岛的 iPhone 显示倒计时，其他设备显示锁屏实时活动。
3. “预览下一门课的灵动岛”可创建一个 5 分钟倒计时。页面会显示系统返回的活动状态和标识；创建被中断、系统拒绝或活动被移除时会明确提示。返回主屏查看紧凑倒计时，长按灵动岛查看完整课程。
4. 要使用系统通知，在课程编辑页设置提前提醒分钟数，然后单独开启“上课提醒”并允许通知。

在“提醒”页设置学校本学期第一周内的日期；课表、通知和小组件共用该学期周次。通知按课程有效周次和具体日期安排，最多保留最近 60 次；每次打开 App 时会补排，长期不打开 App 可能耗尽已安排的通知。本地通知由系统调度，已安排的通知即使 App 没运行也能提醒。iOS 26 可预先计划下一门课的实时活动，页面会区分“已计划”和“已激活”。iOS 17/18 在 App 前台或重新进入前台时创建实时活动，创建后返回桌面仍可显示；旧系统若要完全无人值守地远程启动，需要 APNs 服务端。后台期间的课程切换和结束清理会在再次打开 App 时处理；系统也限制单次活动持续时间。

“今日课表”小组件提供小号和中号布局，读取 App Group 中共享的课程数据；课程有变更时 App 会请求 WidgetKit 更新时间线。WidgetKit 按系统时间线预算刷新，因此显示可能稍晚于课程编辑。Live Activity 的课程名称、上课时间、教学楼和节次通过 ActivityKit 内容直接传给系统，不依赖 App Group。

## 使用 Sideloadly 安装

导入 Release IPA 后使用 `Apple ID Sideload`，保持 `Dropping 0 of 1 plugins`，不要删除 `KebiaoWidgetExtension.appex`。安装并首次打开 App 后，到“提醒”页点击“预览下一门课的灵动岛”进行验收；主屏幕长按后选择“编辑”>“添加小组件”>“课表”即可添加“今日课表”。Widget 需要签名配置允许 App Group `group.com.example.kebiao`；免费 Apple ID 的 Sideloadly 签名可能无法授予该 entitlement，遇到小组件缺失或无课程时需使用包含此 App Group 的 provisioning profile。免费 Apple ID 签名通常只有 7 天有效期，需要定期刷新。

## Windows 上的自动编译

学校网页登录使用 WebKit 保留的系统信息，并补齐学校脚本所需的 Safari 浏览器标识。重庆理工大学办事大厅会用浏览器类型生成设备名，缺少这一标识会让登录后的设备名为空。兼容处理在首次导航之前完成，不修改学校的账号、密码、票据或认证请求。

`.github/workflows/ios-ci.yml` 会在每次推送、Pull Request 或手动运行时，使用 GitHub 的 macOS Runner 运行回归测试，编译 App 与 WidgetKit 扩展，并检查“今日课表”及 Live Activity 已注册、小组件共享数据所用的 App Group 已配置、扩展已嵌入。灵动岛 UI 测试实际创建 ActivityKit 活动、返回主屏截图，再返回 App 检查活动仍然激活；截图用于核验显示，活动状态通过不能替代真机显示验收。成功后可在 Actions 的 Artifacts 下载 `Kebiao-simulator-app` 和 `Kebiao-release-ipa`。

Actions 产出的 IPA 未签名，安装到真机前仍需由 Sideloadly 等工具重新签名。真机上使用小组件时，签名所用开发团队必须注册 App Group，并在 App 与 Widget 扩展的 provisioning profile 中包含它；证书、描述文件和密码不得提交进仓库。
