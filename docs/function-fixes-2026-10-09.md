# 功能修复说明

本次处理功能审查记录中的 A01–A12：

- 通知按实际上课日期安排，遵守起止周和单双周；预排最近 60 次，启动或回到前台时补排。通知重排串行执行，过期的编辑快照不会继续写入。
- 合并课程签名包含有效周集合、节数、实际开始时间、具体日期及课长，保留不同安排。
- CSV、文本、HTML 和文字 PDF 保留分段周次与单双周；不再从节次数字猜周次。
- 在提醒页设置学校第一周日期，App 与 Widget 共用。默认学期回退算法将一月归入上一年秋季学期。
- ICS 保留绝对日期和时长，支持单次、DAILY/WEEKLY、INTERVAL、COUNT、UNTIL、EXDATE、RDATE、TZID。复杂规则明确提示跳过；无结束日期仅导入 30 周，其他规则最多两年。
- 教务读取筛选课程表、识别重复表头、遍历同源 iframe；跨域 iframe 提供打开独立页面的入口，并支持网页新窗口链接。
- 灵动岛先过滤未启用提醒的课程，课程显示信息或课长变更时重建活动。前台定时刷新，预览活动有独立保留时间。
- 日程按实际开始时间排序并定时刷新完成状态。
- 原生 Course JSON 可直接解码，保留星期、周次、自定义时间、关闭提醒和颜色。
- 显式节次列支持无单位的范围，例如 5-7、7-7。
- App 统一浅色外观，避免深色文字策略与白色卡片冲突。

版本：App 和 Widget 均为 1.3.4，构建号 10。

验证：网页提取的 5 项 Node 回归用例、Widget 源码配置、YAML/plist 和 diff 格式检查通过。新增 13 项 XCTest 交给 GitHub macOS Xcode 执行；已有测试保留。CI 在测试通过后使用最新稳定版 Xcode 归档，检查嵌入扩展、版本和 SHA-256，再上传未签名 IPA。实际 CI 结果以 GitHub 运行记录为准。

边界：Windows 不提供本地 Xcode 验收；学校实站登录、真实签名/App Group、系统通知投递和真机 Live Activity 仍需设备验收。未加入自动公开发布 Release 的步骤。
