# v1.4.1 导入与系统诊断验收

App 与 Widget：1.4.1 / 17。独立补丁基于 `43ac55b`，草稿 PR 目标为 `codex/timetable-v1-4`。本次只完善导入预览、真实提醒状态和共享数据诊断。

## 使用方式

- 导入的“课程明细”展示每个时段的星期、精确周次、节次、目标课表实际时间、教师和教室。具体日期按目标时区显示，超过三次可展开。PDF 原始周次保留为只读来源，校正后的实际周次单独展示；保存更新当前预览，取消不提交。
- 提醒页区分 App 开关与系统通知权限，显示横幅、声音、当前课表实际待投递数、其他课表遗留请求、下一提醒及最近失败。重新排程不会弹出权限申请。开启提醒仍使用明确的权限申请流程。
- 提醒页可检查共享数据并请求小组件刷新。小组件区分正常无课、尚未同步、共享容器不可用、损坏及版本不支持。有效资料可继续读取，更新时间仅在同步校验值匹配时显示。

## 数据与竞争保护

独立元数据 `kebiao.timetables.sync.v1` 保存版本、实际数据的 SHA-256 和写入时间。保存、迁移与恢复先写课表，再写元数据；不改变课表 JSON 与备份结构。旧 v2 数据缺少元数据时仍有效，只显示更新时间未知。已有无效 v2 数据不回退旧数据，不被示例课程覆盖。

通知客户端可注入。诊断来自系统实际请求队列，并按课表身份隔离非课程通知；单条添加失败不阻止其他提醒，成功重排清除相应失败。排程与查询保留任务代次、完整课表快照及页面查询代次检查，过时的结果不能覆盖新选择。
