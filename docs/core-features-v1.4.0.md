# v1.4.0 核心功能

App 与 Widget：1.4.0 / 16。以 1.3.9 / 15 为基线，保留现有教务、PDF/OCR、文件导入和系统活动能力。

## 数据与迁移

`kebiao.timetables.v2` 保存版本化课表集合及当前选择，每张课表独立包含学期、固定时区、作息和课程。课程共享名称、颜色、学分、备注，时段独立保存重复规则或有稳定 ID 的日期事件。

旧 `kebiao.courses.v1` 和学期键保留不删。旧数据成功解码、校验和编码后才写 v2；空课程仍为空。旧跨长课间安排迁移时保留原课长，新课程默认按学校作息首尾计算。损坏或未知版本暂停编辑，原始资料可导出。完整恢复保存恢复前快照；新增课表导入重建引用 ID，保留例外之间的关联。

## 排程与交互

课表、日程、通知、Widget、实时活动和 ICS 共用实际 `CourseOccurrence`。身份包含课表、时段与原始日期/日期事件 ID；学校作息修改后，停调课仍关联原安排。取消安排不产生提醒，跨日移动仅在目标日期出现，同日多次日期事件独立展示。

课程编辑使用草稿；编辑或导入捕获目标课表，切换当前表不会把资料写进另一张。调停课在具体日期详情操作，也能在课程编辑的调整记录中恢复。默认 12 节/20 周；迁移或导入有 21–30 周时扩大学期，修改设置不能截断已有周次。

完整备份是本地版本化 JSON，系统文件选择器负责读写。ICS 按日期范围展开为独立 VEVENT，采用稳定 UID 和 UTC 时间，按 UTF-8 字节折行；备份承担完整结构恢复。

## 验证

新增模型、迁移、备份、日期往返和系统服务回归测试，以及多课表切换、多时段周次保存、导出预览 UI 测试。现有学校提取和浏览器身份检查保留。macOS CI 在 iPhone 16 Pro、小屏 iPhone SE 和 iPad 运行核心交互，输出截图、模拟器 App、未签名 IPA 与 SHA-256。

实际编译和测试结论以对应提交的 Actions 结果为准。Windows 无本地 Xcode；通知投递、真实签名/App Group 和灵动岛仍需真机验收。
